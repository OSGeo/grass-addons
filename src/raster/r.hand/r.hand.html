DESCRIPTION

r.hand - Height Above Nearest Drainage (HAND) is a terrain-based inundation model that uses a digital elevation model (DEM) to calculate the height of the terrain above the nearest stream (Nobre et al., 2011). The HAND model is used to estimate flood potential during a flood event. The r.hand tool calculates the HAND raster map from a DEM raster map with options to provide precomputed streams and flow direction raster maps. The tool will return an inundation raster map or times series (STRDS) of inundation raster maps based on user define water levels.
