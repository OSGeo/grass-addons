## DESCRIPTION

Delineate the upstream contributing area ('sub-watershed') and stream
sections ('sub-stream') for each grid cell of a stream network.

The results are written to the directory given by the **folder** option.
The module refuses to use a directory that is not empty unless the
**--overwrite** flag is given. With **--overwrite**, only the files and
directories created by a previous run of the module are replaced; other
content of the directory is kept.
